Geekshed ChanServ Commands:

  • /cs register #channel <password> [description] - Register channel & become Founder.
  • /cs info #channel - View channel registration & Founder info.
  • /cs aop | sop | hop | vop #channel add|del|list <nick> - Manage Access Lists.
  • /mode #channel +r / +i / +m / +k - Set channel modes.

UnrealIRCd Oper & Admin Commands:

  • /OPER <userid> <password> - Authenticate as IRC Operator / Admin.
  • /SAJOIN <nick> <#channel> - Force user to join channel.
  • /SAPART <nick> <#channel> - Force user to part channel.
  • /SAMODE <#channel> <mode> - Force change channel modes.
  • /KILL <nick> [reason] - Disconnect user from network.
  • /SHUN [+|-]<nick|ip> [time] [reason] - Shun / mute target user globally.
  • /KLINE | /ZLINE | /GLINE | /GZLINE [+|-]<nick|ip> [reason] - Network bans.
  • /WALLOPS | /GLOBOPS | /CHATOPS | /ADCHAT <msg> - Oper broadcast channels.
  • /SETHOST <vhost> | /CHGHOST <nick> <vhost> - Identity vhost cloaking.
  • /REHASH | /HTM [ON|OFF] | /CLOSE - Server administration.
